# Changelog

All notable changes to the Mono Archive store repository will be documented in this file.

## [1.0.0] - 2026-10-09
### Added
- Core Laravel 11 foundation with SQLite database support.
- Pure CSS strict monochrome design system (white background, black accents).
- Storefront homepage with hero welcome greeting and product catalog list.
- Interactive WhatsApp order link builder with live preview and clipboard copy.
- Comprehensive administrative panel for products, categories, blog, and store configurations.
- Editorial journal/blog module.
- Single-enter shell deployment scripts (deploy.sh, redeploy.sh, runtest.sh).
- Domain value objects, services, actions, and REST API v1 endpoints.
- 100+ granular, production-grade micro-commits.
